>Sonia Flower Shop 🌸

A responsive e-commerce web application designed for a floral boutique, featuring a modern user interface and functional shopping experience.

> Live Demo
You can view the live project here: [https://sonia-webd-ev.github.io/sonia-flower-shop/]

> Features
* Interactive Shopping Cart: Real-time management of flower selections using JavaScript.
* Service Request Form: A community portal allowing users to submit specific floral service requests.
* Responsive Design: Fully optimized for mobile, tablet, and desktop views using Bootstrap.
* User Authentication: Built-in validation for user login and contact forms.

> Technologies Used
* HTML5: Semantic structure for better SEO and accessibility.
* CSS3: Custom floral-themed styling and layout.
* Bootstrap 5: Framework for rapid, responsive UI development.
* JavaScript: Used for cart logic, form validation, and DOM manipulation.

> Project Structure
* index.html- The main landing page.
* css/ - Custom stylesheets for the floral theme.
* js/ - JavaScript files for functionality.
* images/ - Assets for various flower categories and shop branding.
